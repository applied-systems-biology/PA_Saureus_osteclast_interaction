This is the JIPipe (https://jipipe.org) project that is used to analyze the amount and spatial distribution of Staphylococcus aureus in a bone-like model consisting of osteoblasts and osteoclasts. The full details of the analysis can be found in 
Raupach et al., Palmitic acid promotes S. aureus bone infection in osteomyelitis models by impairing osteoclast-mediated bacterial clearance, Under Review.
The image data connected to this code can be found at https://doi.org/10.5281/zenodo.22080816.

If any data or code is used, please cite the above publication.
